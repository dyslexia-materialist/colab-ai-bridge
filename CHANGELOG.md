# Changelog

## 0.9.0 — English Workspace

- Replaced the legacy Turkish panel with a responsive, English-language chat workspace.
- Added left-side conversations, chat export and browser-local persistence, a new-chat action, and a compact mobile menu.
- Added accessible light/dark theme toggle and a model configuration drawer.
- Preserved existing `/api` routes for chat, text-to-image, image-to-image, GGUF and real estate covers.
- Improved the English status and error strings, English listing support, and HTML no-store caching.
- Split editable sources from generated single-cell distributions for GitHub maintenance.
- UI and sample API interactions validated with browser mocks; Python source and worker syntax checked; actual Colab GPU model loading remains unverified for this release.
